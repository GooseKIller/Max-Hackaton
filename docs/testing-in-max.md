Локально: `PROCULTURE_API_KEY='' DB_PATH=data/console-local.db python backend/console.py`.
`backend/app/config.py` автоматически читает закрытые параметры локального `.env`.
`python backend/runner.py` запускает собственный polling; не запускайте параллельно процессу
Антона и не используйте одновременно с webhook.
