В Python-тестах остаётся предупреждение Starlette о будущей замене `httpx` в
тестовом клиенте; ошибок тестов нет. Время сборки относится только к указанной
машине и не гарантирует такое же время на сервере проверяющих.

Браузерные тесты выполнены в Linux Chromium с мобильным и настольным размерами
экрана. Это не проверка встроенного браузера MAX, Safari или реальных iOS/Android.
GitHub Actions запускает Python-тесты, frontend build/format и Docker build;
успешный CI относится к указанному commit и не подтверждает доставку напоминаний
или прохождение сценария на каждой платформе MAX.
